# AGENTS.md

## Objetivo do projeto

Clone do [TabNews](https://tabnews.com.br) desenvolvido com agentes de IA, como parte do [curso.dev](https://curso.dev).

## Stack

- Next.js (App Router)
- React
- JavaScript (sem TypeScript)
- CSS global puro (sem framework de estilos)

## Comandos

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — build de produção
- `npm start` — executa o build de produção
